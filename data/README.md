# data/ — 보정값과 참값 라벨 (깃으로 공유)

이 폴더는 프로그램이 저장하는 **보정값과 참값 라벨**입니다. 여기에 있는 건
**숫자와 좌표뿐**입니다 — **이미지는 들어가지 않습니다.** 그래서 깃에 커밋해도
보안 문제가 없고, 파일 크기도 몇 KB입니다.

깃 저장소 안에서 프로그램을 실행하면 여기에 자동 저장됩니다. 커밋·푸시하면
보정값이 저장소에 올라가고, **다른 컴퓨터에서 받으면(pull) 그대로 적용**됩니다.
(저장소 밖에서 설치해 쓰면 홈 폴더 `~/.tem_analyzer/`에 저장되어 이 폴더는 안 씁니다.)

## 파일

- **`settings.json`** — 분석 설정과 **벽 위치 보정값**(`wall_place`). 벽 위치는
  배율에 무관한 비율이라, 한 번 정하면 같은 시료의 다른 배율 이미지에도 적용됩니다.
- **`labels.json`** — 이미지별 **참 지름 라벨**. 각 라벨은 `{좌표, 참지름, 측정값, 시각}`
  이고, **번호가 아니라 좌표에 묶여** 있어 재분석해도 유지됩니다. 이미지 키는
  `파일명|가로x세로` 형식입니다(이미지 내용이 아니라 이름·크기만).

## 다른 컴퓨터로 옮기기

1. 이 파일들을 커밋·푸시합니다 (또는 이 작은 JSON을 그대로 공유/업로드).
2. 다른 컴퓨터에서 저장소를 받으면(pull) 프로그램이 시작할 때 자동으로 불러옵니다.

이미지 파일이 아니라 **이 숫자 파일만** 오가면 되므로, 원본 이미지를 올리지 않고도
보정·라벨을 여러 대에서 공유할 수 있습니다.
