# TEM Particle Analyzer

TEM(투과전자현미경) 이미지에서 구형 입자를 자동으로 검출하고 크기를 측정하는 프로그램입니다.

## 주요 기능

- **자동 입자 검출**: 씨앗 원을 잡은 뒤 실제 입자 경계를 방사형으로 추적하고, 그 윤곽에 원을 재적합해 직경을 구합니다.
  빽빽하게 쌓인 중공 입자는 **자기 쉘로 둘러싸인 밝은 내부**를 먼저 찾아 입자를 잡습니다 —
  중심에서 뻗은 광선만으로는 자기 쉘과 이웃의 쉘을 구분하지 못해 원이 옆으로 밀리거나
  여러 입자를 감싸버리는데, "무엇에 둘러싸여 있는가"는 그런 혼동이 없기 때문입니다
- **외경 측정**: 입자 크기는 **바깥 지름(외경)** 입니다. 어두운 쉘 벽 위 어디가 표면인지는
  방향마다 다릅니다 — **이웃과 맞닿은 쪽은 두 벽이 겹쳐 보이므로 그 한가운데**가 표면이고,
  **빈 공간을 향한 쪽은 자기 벽 하나뿐이므로 그 바깥 끝**이 표면입니다.
  하나의 값을 모든 방향에 똑같이 쓰면 둘 중 하나는 반드시 틀리므로, 방향별로 따로 판단합니다.
  마지막에 **모든 원을 자기 쉘 벽 위로 다시 맞춥니다** — 이 판단이 이미지 단위 투표에 걸려
  쓰이지 않으면 원이 벽의 안쪽 가장자리에 앉아 어두운 띠 전체가 원 밖으로 나가는데,
  실제 시료 9장 중 6장이 그 상태였고 한 장은 중앙값이 7.2%, 최악은 15% 작게 측정됐습니다
- **품질 3등급 분류**: 경계가 충분히 보이는 입자(정상), 일부만 보이지만 보이는 호로 외삽 가능한 입자(근사), 판별 불가 입자(제외)로 나눠 표시하고 제외분은 통계에서 뺍니다
- **겹친 입자 분리**: 뭉쳐서 하나로 잡힌 덩어리를 재탐색해 개별 입자로 분리
- **Hollow / Yolk-shell 지원**: 속이 빈 입자 검출 모드, 코어 유무 자동 판정 + 화면 클릭으로 수동 보정
- **불량 입자 판정 + 개수**: 코어가 남았거나 쉘이 내부로 무너진 입자를 찾아 **파란 안쪽 원**으로 표시하고
  개수·비율을 통계에 넣습니다. **버리지 않고 표시만 합니다** — 깨진 입자에도 외경은 있고,
  몇 개가 깨졌는지가 그 자체로 결과이기 때문입니다
- **비원형 입자 표시**: 지름은 구를 전제한 값입니다. 길쭉하거나 두 개가 뭉친 입자도 원이 그려지고
  숫자가 나오는데, 그 숫자만 봐서는 원래 모양이 둥글지 않았다는 걸 알 수 없습니다.
  쉘 벽이 적합된 원에서 얼마나 벗어나는지로 판정해 **번호를 자홍색으로** 표시합니다
- **쉘 두께 / 공극률**: 안쪽 공동 경계를 찾아 쉘 두께와 공극률(부피 기준)을 입자별로 측정
- **화면 확대/이동**: 휠로 확대, 드래그로 이동 — 스케일바를 정확히 재고 작은 입자를 눈으로 확인할 때 사용
- **스케일바 자동 인식**: OCR을 통한 스케일바 자동 감지 (실패 시 수동 입력)
- **통계 분석**: 개수, 평균, 표준편차, D10/D50/D90, 코어 보유율
- **분포 히스토그램**: 입자 크기 분포를 시각적으로 표시
- **결과 내보내기**: 번호가 매겨진 주석 이미지 저장, Excel 내보내기(데이터 + 통계 + 결과 이미지 시트)

## 지원 이미지 형식

PNG, JPEG, BMP, TIFF를 지원합니다. TEM 카메라가 쓰는 16-bit·float TIFF는 값이 컨테이너 범위의 일부만
차지하는 경우가 많아(예: 16-bit 파일 안의 12-bit 데이터) 실제 밝기 범위를 기준으로 8-bit 변환합니다.
핫픽셀·데드픽셀에 명암이 좌우되지 않도록 백분위수 기준으로 스트레칭합니다. 멀티페이지 TIFF는 첫
페이지만 읽습니다.

## 설치

```bash
pip install -r requirements.txt
```

이것만으로 바로 실행 가능합니다. 스케일바는 수동으로 입력하면 됩니다.

### (선택) 스케일바 자동 OCR 인식

스케일바 텍스트를 자동으로 읽으려면 Tesseract OCR을 추가 설치하세요:

```bash
pip install pytesseract
```

+ Tesseract 바이너리 설치:
- Ubuntu/Debian: `sudo apt install tesseract-ocr`
- macOS: `brew install tesseract`
- Windows: [UB-Mannheim Tesseract](https://github.com/UB-Mannheim/tesseract/wiki) 에서 설치

설치하지 않아도 프로그램은 정상 동작하며, 수동 입력 모드로 자동 전환됩니다.

## 실행

**간편 실행**: 폴더 안의 `START-Windows.bat`(윈도우) 또는 `START-Mac.command`(맥)를 더블클릭하면
패키지 설치부터 실행까지 자동으로 진행됩니다.

**명령어로 실행**: `run.py`가 있는 폴더에서 명령창을 열고

```bash
py -m pip install --user -r requirements.txt   # 처음 한 번만
py run.py
```

`py`가 없으면 `python` 또는 `python3`으로 바꿔 쓰세요. `py`를 쳤을 때 사용법 도움말만
나온다면 Python Install Manager만 깔리고 파이썬 본체가 없는 상태이므로,
`py install 3.13`으로 런타임을 먼저 받으세요. `--user`는 관리자 권한 없이
설치하기 위한 옵션입니다. `py run.py` 대신 `py -m tem_analyzer`로도 실행됩니다.

폴더에서 명령창을 여는 방법: 파일 탐색기 **주소창**을 클릭해 경로가 선택되면 `cmd`를 입력하고 Enter.

## 사용법

1. **이미지 열기** - TEM 이미지 파일(PNG, JPG, TIFF 등)을 선택합니다
   - **마우스 휠**로 확대/축소하고, **드래그**로 이동합니다 (커서 위치를 기준으로 확대됩니다).
     이미지 아래의 `+` / `−` / **맞춤** 버튼과 배율 표시로도 조작할 수 있습니다.
     스케일바를 재는 중일 때는 왼쪽 드래그가 측정이므로 **가운데 버튼 드래그**로 이동합니다
2. 스케일바 배율을 맞춥니다 (이걸 안 하면 측정값이 전부 틀립니다)
   - **이미지에서 스케일바 재기** 버튼을 누른 뒤, 이미지 위의 스케일바를 따라 드래그하면
     픽셀 길이가 자동으로 입력됩니다. 드래그가 몇 픽셀 어긋나도 이미지 안의 막대를 찾아
     그 실제 길이로 맞춰줍니다 (상태 표시줄에 보정된 값이 표시됩니다)
   - **Shift를 누른 채 드래그하면 선이 수평/수직으로 고정**됩니다. 손으로 그은 선은
     조금씩 기울고, 기울어진 만큼(코사인) 길이를 짧게 읽어 배율이 어긋납니다.
     드래그하는 동안 현재 픽셀 길이가 상태 표시줄에 실시간으로 표시됩니다
   - **양 끝을 한 번씩 클릭해도 됩니다.** 첫 번째 끝을 클릭한 뒤 확대(휠)·이동(가운데 버튼
     드래그)하고 반대쪽 끝을 클릭하면 측정됩니다. 스케일바가 한 화면에 다 안 들어갈 만큼
     확대했을 때는 이 방법을 쓰세요. `Esc`로 취소합니다
   - **실제 길이**와 **단위**를 스케일바에 적힌 값으로 맞춥니다 (예: 100 / nm)
3. 필요 시 분석 파라미터를 조정합니다
   - 최소/최대 면적, 원형도 필터
   - **Hollow 입자 모드**: 속이 빈 실리카 등 링 형태 입자 (기본 켜짐, 일반 입자에서도 손해 없음)
   - **쉘 두께 / 공극률 측정**: 중공 입자의 공동 경계를 찾아 쉘 두께와 공극률을 계산
     (공동이 뚜렷하지 않은 입자는 측정하지 않고 `-`로 표시됩니다)
   - **코어 검출**: yolk-shell 입자의 코어 유무 판정
   - **구(球) 모서리 보정** (기본 꺼짐): 구는 가장자리로 갈수록 두께가 0으로 얇아져,
     초점이 아무리 좋아도 경계가 계단이 아니라 서서히 사라지는 모양입니다. 밝기
     기준으로는 그 지점을 잡을 수 없어 **실제보다 1픽셀쯤 작게** 나옵니다
     (반지름 30px에서 -3.1%, 60px에서 -1.9%, 120px에서 -1.6%). 이 옵션은 대비의
     제곱이 반지름에 대해 직선이 되는 성질로 외경을 직접 구해 **오차를 ±0.9% 안으로**
     줄입니다. 다만 두께가 일정한 원반형 입자는 1픽셀쯤 크게 읽습니다.
     **실제 TEM 입자는 구이므로 대개 켜는 쪽이 맞습니다**
   - **경계 자동 판단** (기본 켜짐, 권장): 쉘 벽 위 표면의 위치를 방향마다 따로 정합니다.
     이웃과 맞닿은 쪽은 벽 한가운데, 빈 공간을 향한 쪽은 벽의 바깥 끝입니다
   - **경계 기준 (%)**: 위 자동 판단을 껐을 때만 쓰입니다. 테두리(링) 위 어디를 경계로 볼지
     정합니다. **0% = 링 안쪽 가장자리, 50% = 링 한가운데, 100% = 링 바깥 가장자리**(양쪽 모두
     반높이 기준). 입자 크기는 외경이므로 기본값은 바깥 가장자리인 **95%**입니다.
     **손으로 재던 값과 어긋나면 이 값으로 맞추세요** (낮추면 작게, 높이면 크게 측정)
   - **미측정 구간 가늘게 표시**: 입자끼리 맞닿아 경계가 보이지 않는 구간을 가는 선으로
     구분합니다. 어디까지가 실측인지 확인할 때 켜세요 (기본 꺼짐 - 경계선을 한 굵기로 그림)
   - **경계 보정 (직접 재기)**: 흐릿한 쉘 벽 위 어디가 '표면'인지는 보는 사람마다 다릅니다.
     이 값을 자동으로 정하는 대신 **사람의 판단에 맞추는** 기능입니다. **분석을 한 번 돌린 뒤**
     `지름 재기 시작`을 누르고 입자 3개 이상의 지름을 가로질러 드래그한 다음 `보정 적용`을
     누르면, 그 측정을 기준으로 **전체 입자의 지름을 다시 잡습니다**. 검증: 합성 시료에서
     입자 8개를 손으로 재 보정하면, **재보지 않은 나머지** 입자의 외경 오차가 -2.9%에서
     +0.5%로 줄었습니다. 한 번 보정하면 **같은 시료의 다른 배율 이미지에도 그대로 적용**됩니다
     (벽 위 표면 위치는 시료의 성질이지 배율의 문제가 아니기 때문입니다). `초기화`로 자동 판단
     복귀. 겹쳐 쌓여 이웃-거리 검증을 쓸 수 없는 시료에서 특히 유용합니다
   - **보정값 지속 / 설정 저장·불러오기**: 한 번 보정하면 **프로그램을 껐다 켜도 자동으로
     다시 적용**됩니다(보정 적용 시 자동 저장 → 다음 실행 때 자동 복원). 시료가 여러 개면
     `설정 저장…`으로 이름 붙인 `.json` 파일로 내보내고 `설정 불러오기…`로 골라 씁니다.
     보정값과 분석 파라미터가 함께 저장됩니다 — **배율(스케일바)은 이미지마다 다르므로
     저장하지 않습니다**. 파일은 사람이 읽고 편집할 수 있는 JSON이라 다른 PC로 옮기거나
     공유할 수 있습니다
   - **참값 라벨링 (데이터 기록)**: 입자의 **참 지름을 손으로 재서 기록**해 두는 기능입니다.
     보정과 달리 **측정값을 전혀 바꾸지 않습니다** — 참값을 데이터로만 쌓습니다. `라벨 클릭
     시작`을 누르고 입자를 클릭하면 그 자리에 참 지름을 입력하고(측정값이 미리 채워지니
     맞으면 확인, 틀리면 수정), **번호가 아니라 위치에 묶여** 저장되므로 재분석해서 번호가
     바뀌어도 유지됩니다. 같은 곳을 다시 클릭하면 수정, `0` 입력은 삭제. `정확도 리포트`로
     라벨 대비 측정 오차(평균·편향)를, `CSV 내보내기`로 전체 데이터를 뽑습니다. 라벨은
     이미지별로 자동 누적되어 프로그램을 껐다 켜도 남습니다. **참값은 알고리즘과 무관한
     사실**이라, 프로그램을 개선한 뒤 같은 라벨에 다시 대보면 정확도가 얼마나 나아졌는지
     바로 확인됩니다. (정확도로 읽으려면 틀린 것만 말고 **대표 입자를 골고루** 라벨하세요.)
4. **분석 실행** - 입자가 검출되고 측정됩니다
5. 결과 확인 및 보정
   - 초록: 정상 측정 / 노랑: 근사 측정 / 보라: 다른 검출과 겹침 /
     **주황: 확인 필요** / 빨강: 제외 (번호 없음, 통계 미포함)
   - **파란 안쪽 원: 불량 입자** (코어 잔존 또는 내부 파손). 테두리 색은 그대로 두므로
     측정 품질과 불량 여부를 함께 볼 수 있습니다. 통계 패널과 Excel에 개수가 나옵니다
   - **자홍색 번호: 비원형 입자** (길쭉하거나 뭉친 것). 지름은 나오지만 구가 아니므로
     의미가 약합니다. 표와 Excel에서 걸러낼 수 있습니다
   - **주황(확인 필요)은 지운 것이 아니라 넘긴 것입니다.** 입자가 없는 자리에 생긴 유령은
     둘레에 어두운 링이 부분적으로만 있는데, 이웃에 둘러싸여 자기 둘레가 덜 보이는 진짜
     입자도 똑같이 나옵니다. 실제 이미지에서 두 무리의 측정값 범위가 완전히 겹쳐
     기계가 가릴 수 없으므로, 지우는 대신 따로 표시합니다.
     **화면에서 클릭하면 통계에 포함**되고, 다시 클릭하면 제외됩니다
   - 검출 개수가 눈으로 보이는 입자 수보다 많아 보이면: 보라색으로 표시된 겹치는 검출을
     먼저 확인하고, 표의 **직경 열 머리글을 클릭해 정렬**하면 유난히 작거나 큰 값이
     바로 드러납니다
   - 확대해서 봐도 클릭 판정은 그대로입니다. 확대한 상태에서 작은 입자를 정확히 클릭할 수 있습니다
   - 코어 검출을 켠 경우, 화면에서 **입자를 클릭하면 코어 체크가 토글**됩니다.
     자동 판정은 초안이므로 육안으로 확인해 보정하세요
6. **결과 이미지 저장** / **Excel 내보내기** - 번호가 매겨진 이미지와 측정 데이터를 저장합니다
   (Excel에는 데이터·통계 시트와 함께 결과 이미지가 포함됩니다)

## 참고

- 이미지 테두리에 걸친 입자도 **둘레의 2/3 이상이 화면 안에 있으면 측정합니다.**
  지름을 정하는 데 원 전체가 필요하지는 않기 때문입니다. 그보다 더 잘린 것만 제외하고
  빨간색으로 표시합니다. (한때 테두리에 닿은 입자를 전부 뺐는데, 그러면 배율마다 빼는
  비율이 달라 — 넓은 시야는 가장자리에 작은 입자가 많고 확대 시야는 큰 입자 몇 개뿐 —
  같은 시료의 배율 간 측정값이 오히려 벌어졌습니다.)
- **측정이 맞는지는 "배율끼리 값이 같은가"로 확인하지 않습니다.** 같은 시료라도
  고배율 화면에는 입자가 스무 개뿐이고, 그 스무 개가 저배율 화면의 400개와 같은
  무리일 이유가 없습니다. 실제로 **경계와 무관한 값인 이웃 간 거리(nm)** 조차 같은
  시료의 두 배율 사이에서 최대 6% 차이가 납니다. 대신 **원 지름을 이웃까지의 거리와
  비교**합니다 — 빽빽하게 쌓인 단층은 서로 닿아 있으므로 이 비율이 1 근처여야 하고,
  이 값은 스케일바에도 밝기 모형에도 의존하지 않습니다. 쉘 벽 안쪽에 앉은 원은
  0.93으로, 이웃의 벽까지 삼킨 원은 1.10으로 읽혀 바로 드러납니다
- 전체 해상도(2048² 이상) 이미지는 분석에 수 초에서 수십 초가 걸릴 수 있습니다.
  입자 표면 질감이 강한 대형 이미지일수록 씨앗 검출(Hough 변환) 단계가 오래 걸립니다.
  **분석 실행 버튼 아래 진행 막대**에 현재 단계(전처리 / 입자 검출 / 경계 정렬 / 판별 …)와
  진행률이 표시되므로, 오래 걸려도 멈춘 것인지 진행 중인지 알 수 있습니다.
