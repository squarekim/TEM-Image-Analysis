# TEM Particle Analyzer

TEM(투과전자현미경) 이미지에서 구형 입자를 자동으로 검출하고 크기를 측정하는 프로그램입니다.

## 주요 기능

- **자동 입자 검출**: 씨앗 원을 잡은 뒤 실제 입자 경계를 방사형으로 추적하고, 그 윤곽에 원을 재적합해 직경을 구합니다
- **품질 3등급 분류**: 경계가 충분히 보이는 입자(정상), 일부만 보이지만 보이는 호로 외삽 가능한 입자(근사), 판별 불가 입자(제외)로 나눠 표시하고 제외분은 통계에서 뺍니다
- **겹친 입자 분리**: 뭉쳐서 하나로 잡힌 덩어리를 재탐색해 개별 입자로 분리
- **Hollow / Yolk-shell 지원**: 속이 빈 입자 검출 모드, 코어 유무 자동 판정 + 화면 클릭으로 수동 보정
- **스케일바 자동 인식**: OCR을 통한 스케일바 자동 감지 (실패 시 수동 입력)
- **통계 분석**: 개수, 평균, 표준편차, D10/D50/D90, 코어 보유율
- **분포 히스토그램**: 입자 크기 분포를 시각적으로 표시
- **결과 내보내기**: 번호가 매겨진 주석 이미지 저장, Excel 내보내기(데이터 + 통계 + 결과 이미지 시트)

## 지원 이미지 형식

PNG, JPEG, BMP, TIFF를 지원합니다. TEM 카메라가 쓰는 16-bit·float TIFF는 값이 컨테이너 범위의 일부만
차지하는 경우가 많아(예: 16-bit 파일 안의 12-bit 데이터) 실제 밝기 범위를 기준으로 8-bit 변환합니다.
핫픽셀·데드픽셀에 명암이 좌우되지 않도록 백분위수 기준으로 스트레칭합니다. 멀티페이지 TIFF는 첫
페이지만 읽습니다.

## 설치

```bash
pip install -r requirements.txt
```

이것만으로 바로 실행 가능합니다. 스케일바는 수동으로 입력하면 됩니다.

### (선택) 스케일바 자동 OCR 인식

스케일바 텍스트를 자동으로 읽으려면 Tesseract OCR을 추가 설치하세요:

```bash
pip install pytesseract
```

+ Tesseract 바이너리 설치:
- Ubuntu/Debian: `sudo apt install tesseract-ocr`
- macOS: `brew install tesseract`
- Windows: [UB-Mannheim Tesseract](https://github.com/UB-Mannheim/tesseract/wiki) 에서 설치

설치하지 않아도 프로그램은 정상 동작하며, 수동 입력 모드로 자동 전환됩니다.

## 실행

**간편 실행**: 폴더 안의 `START-Windows.bat`(윈도우) 또는 `START-Mac.command`(맥)를 더블클릭하면
패키지 설치부터 실행까지 자동으로 진행됩니다.

**명령어로 실행**: `run.py`가 있는 폴더에서 명령창을 열고

```bash
py -m pip install --user -r requirements.txt   # 처음 한 번만
py run.py
```

`py`가 없으면 `python` 또는 `python3`으로 바꿔 쓰세요. `py`를 쳤을 때 사용법 도움말만
나온다면 Python Install Manager만 깔리고 파이썬 본체가 없는 상태이므로,
`py install 3.13`으로 런타임을 먼저 받으세요. `--user`는 관리자 권한 없이
설치하기 위한 옵션입니다. `py run.py` 대신 `py -m tem_analyzer`로도 실행됩니다.

폴더에서 명령창을 여는 방법: 파일 탐색기 **주소창**을 클릭해 경로가 선택되면 `cmd`를 입력하고 Enter.

## 사용법

1. **이미지 열기** - TEM 이미지 파일(PNG, JPG, TIFF 등)을 선택합니다
2. 스케일바 배율을 맞춥니다 (이걸 안 하면 측정값이 전부 틀립니다)
   - **이미지에서 스케일바 재기** 버튼을 누른 뒤, 이미지 위의 스케일바 양 끝을 드래그하면
     픽셀 길이가 자동으로 입력됩니다
   - **실제 길이**와 **단위**를 스케일바에 적힌 값으로 맞춥니다 (예: 100 / nm)
3. 필요 시 분석 파라미터를 조정합니다
   - 최소/최대 면적, 원형도 필터
   - **Hollow 입자 모드**: 속이 빈 실리카 등 링 형태 입자
   - **코어 검출**: yolk-shell 입자의 코어 유무 판정
4. **분석 실행** - 입자가 검출되고 측정됩니다
5. 결과 확인 및 보정
   - 초록: 정상 측정 / 노랑: 근사 측정 / 빨강: 제외 (번호 없음, 통계 미포함)
   - 코어 검출을 켠 경우, 화면에서 **입자를 클릭하면 코어 체크가 토글**됩니다.
     자동 판정은 초안이므로 육안으로 확인해 보정하세요
6. **결과 이미지 저장** / **Excel 내보내기** - 번호가 매겨진 이미지와 측정 데이터를 저장합니다
   (Excel에는 데이터·통계 시트와 함께 결과 이미지가 포함됩니다)

## 참고

- 이미지 테두리에 걸쳐 잘린 입자는 직경을 확정할 수 없어 통계에서 제외됩니다.
- 전체 해상도(2048² 이상) 이미지는 분석에 수 초에서 수십 초가 걸릴 수 있습니다.
  입자 표면 질감이 강한 대형 이미지일수록 씨앗 검출(Hough 변환) 단계가 오래 걸립니다.
